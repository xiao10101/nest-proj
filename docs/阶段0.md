## 本阶段 NestJS 知识点

1. main.ts 引导流程：NestFactory.create(AppModule) → 全局配置 → listen。工厂创建的是整个 IoC 容器。
2. Module 三要素：imports / controllers / providers / exports。exports 决定"别的模块能不能注入我的 Provider"——这是模块边界的核心，也是后期拆微服务时判断耦合度的依据。
3. ConfigModule.forRoot()：isGlobal 让配置全局可用、validationSchema 让配置在启动时被 Joi 校验、envFilePath 支持多环境覆盖。
4. 全局前缀 setGlobalPrefix：C 端 API 的版本治理入口（后面阶段 10 拆微服务时，网关靠它路由）
5. 依赖注入的两种写法：构造器注入 vs @Inject()（自定义 token，如 CACHE_MANAGER）。
